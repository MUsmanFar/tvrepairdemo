# Magic TV Repairs

Mobile TV repair website for Magic Electronic Repairs in Cape Town.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run build` and `npm start` for a production build.

## Deploy and share

Deploy as a Next.js project. Set `NEXT_PUBLIC_SITE_URL` to the final public HTTPS origin when deploying to a custom domain or a host that does not supply Vercel’s production URL. The site uses it for canonical links, the sitemap and the Open Graph image that WhatsApp uses for link previews.

Business details and enquiry links are defined in `src/config/site.ts`. The standalone logo and illustrated booking video are in `public/magic`.
